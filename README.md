# MV Designer

Site estático em português para apresentar serviços de marketing e design.

## Conteúdo

- Logo original fornecido pelo proprietário.
- Animações de entrada, revelação ao rolar e movimento discreto do logo.
- Serviços, apresentação do estúdio e processo de criação.
- Pedido de orçamento que abre o WhatsApp com o resumo do projeto.
- Menu móvel e visualização dos exemplos de portfólio em modal.
- Respeito à preferência de movimento reduzido e navegação por teclado.

## Portfólio

Nexo e Alva são exemplos conceituais com imagens geradas por IA para demonstração. Não representam trabalhos realizados pelo proprietário nem clientes reais. Substitua as imagens, descrições e nomes pelos projetos reais antes de usar como comprovação de portfólio.

## Publicação

Os arquivos funcionam ao abrir `index.html` e não dependem de instalação ou compilação. Para GitHub Pages, use a branch `main` e a pasta raiz (`/root`) nas configurações do repositório. O repositório já tinha GitHub Pages habilitado no momento desta entrega.

Edite `index.html` para os textos, `styles.css` para a aparência e `script.js` para os detalhes dos projetos e o formulário.
